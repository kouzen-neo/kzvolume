# kzvolume Project Instructions

## General Rules
- **Language:** All code, comments, and documentation must be in English.
- **Modern Standards:** Use modern Android development practices (Kotlin, Jetpack, Material Design 3).
- **Professionalism:** Code must be highly optimized, clean, and minimal.

## App Overview
kzvolume restores volume controls for devices with broken or unresponsive physical volume buttons. It provides on-screen access via Floating Button, Edge Swipe gestures, Notification Actions, and Quick Settings tile.

## Project Structure
- `app/src/main/kotlin/io/github/kouzen/kzvolume/`: Main source code.
- `core/`: Core features, permissions, and preferences.
- `features/`: Specific features (floating button, edge swipe, quick tile).
- `home/`: Main UI logic.
